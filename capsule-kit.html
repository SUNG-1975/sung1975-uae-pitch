SUNG —1975— · UAE-ONLY CAPSULE · GENERATION KIT

Render the UAE capsule.

Six climate-appropriate pieces from SUNG1975's catalog — tees, tanks, shorts, light pants, mesh longsleeve. Each pairs with a paste-ready Gemini prompt that turns the source garment into a UAE-only mockup with modern Arabic calligraphy. Output goes into §11 of the deck.

How to use
  1. Click Download on any product card — original image saves locally.
  2. Open Gemini (or any image-gen model with image input — Sora, Midjourney V7, Nano Banana).
  3. Attach the downloaded image.
  4. Click Copy prompt and paste — adjust the Arabic word from the appendix if you want a variant.
  5. Generate. Save the output to /sung1975-uae-pitch/assets/uae-capsule/ for use in the deck.
